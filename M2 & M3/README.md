## Structure
- `data/raw/ml-100k/`: Raw dataset (already downloaded)
- `data/processed/ml100k_clean.csv`: Clean, analysis-ready data
- `docs/preprocessing_log.md`: Preprocessing steps and rationale
- `docs/data_quality.md`: Data quality summary (null rates, distributions, schema, outlier handling)

## Checklist vs. Assignment Requirements
1) Raw dataset or reproducible acquisition: `data/raw/ml-100k/` 
2) Preprocessing log: `docs/preprocessing_log.md` documents steps, rationale, run info.
3) Cleaned dataset: `data/processed/ml100k_clean.csv`.
4) Data quality summary: `docs/data_quality.md` (null rates, class balance via rating distribution, schema, outlier notes).
